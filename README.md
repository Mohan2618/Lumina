# 🍓 Berry – Intelligent Image Processing Chatbot

Berry is an AI-powered image processing chatbot.

Upload an image and describe what you want in natural language.

Examples:

- Can you detect objects in this image?
- What is in this picture?
- Convert this into black and white
- Show me the edges
- Make this image blurry

Berry understands natural language instructions.
